# Marken

Alle auf dieser Seite oder in den aufgelisteten Projekten erwaehnten Produktnamen, Logos und Marken sind Eigentum ihrer jeweiligen Inhaber. Die Verwendung dieser Namen dient ausschliesslich der Identifikation und bedeutet weder eine Verbindung zum Hersteller noch eine Billigung oder Unterstuetzung durch diesen.

Dieses Projekt ist eine unabhaengige Community-Initiative und steht in keiner Verbindung zu einem Hersteller.
